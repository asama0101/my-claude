# ソースコードを正解とする

事実確認の原則（不発明制約）は `~/.claude/agents/doc-updater.md`「主要原則」1番、詳細な確認対象は `~/.claude/agents/references/doc/design.md`・`~/.claude/agents/references/doc/writing.md` の該当箇所を参照する。本ファイルでは重複させず、docwright 固有の補足のみを記す。

## docwright 固有の補足

- **推測で数値・選択肢を捏造しない**: 閾値・バージョン番号・選択肢の列挙等、ソースに根拠のない値を「それらしく」補完しない。17種類の文書はいずれも実装済みシステムを記述するため、記載事実は必ずソース（コード・設定ファイル・DDL・ログ出力）から取得する。
- **裏付けが無ければ「未確認」と明示する**: 確認手段が無い（実機が無い・ソースが未実装等）場合は、それらしい値で埋めずに「未確認」「未規定」と明記する。欠落の明示は捏造より常に望ましい。
- **執筆後は検証委譲が前提**: 各 docwright サブエージェントは自分の書いた文書を自分で照合・承認しない。執筆が終わったら Main に報告し、`doc-verifier` による事実照合（ソースとの突合）を経てから完成とする。
