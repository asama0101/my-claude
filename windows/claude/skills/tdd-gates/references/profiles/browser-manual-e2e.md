# 言語プロファイル: 静的HTML / claude-in-chrome 手動E2E

ビルド・パッケージマネージャ・自動テストランナーを一切持たない単一HTMLファイルアプリ（例: bookmark-shelf の
`bookmarks.html` / `bookmarks-filesync.html`）向け。unit/integrationレイヤーはDOMに密結合しており分離できないため、
**全テストをe2eとして扱う**。テストコードは書かず、claude-in-chromeで実ブラウザを操作してRED/GREENの証拠を取る。

## テスト種別 → ランナー / パスパターン判定

| 対象パス（例） | テスト種別 | ランナー | テスト置き場 |
|----------------|-----------|----------|--------------------|
| `*.html`（単一ファイルアプリ全体） | e2e | claude-in-chrome（エージェントによるブラウザ操作） | テストコードなし。本プロファイルにシナリオを列挙し、実行ログを `progress.md` に証拠として転記する |

## 実行コマンド

```bash
# 単一テスト（RED/GREEN の証拠）
# claude-in-chromeで対象HTMLファイルを file:// で開き、
# 1. 対象のキー操作シーケンスを送る
# 2. document.activeElement.id / tabindex属性 / hidden属性 などをJS評価で確認する
# 3. スクリーンショットとJS評価結果を証拠として記録する
（自動化スクリプトなし。claude-in-chromeツール呼び出しの手順として都度実施）

# 全体（既存回帰の確認）
# 下記シナリオ一覧を全件、実装後にもう一度流す

# カバレッジ
# 自動カバレッジ計測なし。キーマップ全項目（プランに列挙された全ショートカット）を
# 最低1シナリオずつ実行することを最低ラインとする
```

## 層別テストコマンド（CP-B の3層戦略）

このプロジェクトにunit/integrationの分離は存在しない。すべてe2eシナリオとして実施する。

```bash
# unit（該当なし）
-
# integration（該当なし）
-
# e2e（最後の砦・唯一の層）
claude-in-chromeで file:///home/asama/bookmarks-shelf/<対象ファイル>.html を開き、
シナリオごとのキー操作→観測を実施
```

## シナリオ例（bookmark-shelf キーボード対応の場合）

- `/`キーで検索欄(`#search-input`)にフォーカス
  - RED: 実装前はキー押下してもフォーカス移動しない
  - GREEN: `document.activeElement.id === 'search-input'`
- カード一覧で`↓`/`↑`キーによるフォーカス移動
  - GREEN: フォーカス中カードの`tabindex`が`0`、他が`-1`、かつ`document.activeElement`が期待カードと一致
- `Escape`でパネル/フォームが閉じる
  - GREEN: 対象要素の`hidden`属性が付与される
- `n`/`s`/`?`のトグル系ショートカット
  - GREEN: 対象パネルの表示状態（`hidden`属性の有無）がトグルされる

## CI ステージ（CP-E）

このプロジェクトにはCI/ビルドパイプライン自体が存在しない（`package.json`なし、静的HTML配信のみ、CLAUDE.mdの
設計方針として依存ゼロを明言）。**CP-Eは対象外（スキップ）**とする。lintツールの導入もしない。

## Critical 証拠ルール

- **CP-C(RED)**: 実装前にシナリオを実行し、期待する状態変化（フォーカス移動・属性変化）が起きないことをJS評価
  結果またはスクリーンショットで示す。「たぶん効かない」は無効、実際に実行した結果のみ証拠として認める。
- **CP-C(GREEN)**: 実装後に同一シナリオを実行し、期待する状態変化が起きることを示す。かつ既存の全シナリオ
  （回帰確認分）も合わせて実行し失敗0を確認する。
- **CP-C(REFACTOR)**: シナリオ内容（期待する状態変化の定義）は変えず、実装コードのみ変更したことを示す。

## カバレッジ閾値

自動計測なし。プラン記載のキーマップ全項目（グローバル5種＋カード一覧内5種）を、各1シナリオ以上でGREEN
確認することを最低ラインとする。
