# ドキュメントプロファイル: 汎用（generic）

CP-F がドキュメント同期対象として扱うカテゴリと、カテゴリごとの生成トリガー条件を定義する
ゲート用グルー（薄い層）。目次構成（章立て）の正典は `~/.claude/agents/references/doc/design.md`
「文書カテゴリ別 目次テンプレート」節へ委譲する（重複させない）。

## 対象カテゴリ

| カテゴリ | 生成条件（トリガー） | 独立/統合 | 目次テンプレート参照 |
|---------|---------------------|-----------|---------------------|
| README | 常時（コード変更全般で対象） | 独立 | 既存運用（テンプレートなし） |
| ガイド | 常時（コード変更全般で対象） | 独立 | 既存運用（テンプレートなし） |
| API仕様（データスキーマ・IF定義書を含む） | 常時（IF/エンドポイント/DBスキーマに触れる変更） | 独立（データスキーマ・IF定義書はここに統合、独立カテゴリ化しない） | doc/design.md §API仕様（データスキーマ・IF定義書統合） |
| セキュリティ・認証情報管理設計書 | 条件付き: diffが認証/秘密情報/鍵管理コードに触れる場合のみ | 独立 | doc/design.md §セキュリティ・認証情報管理設計書 |
| リリースノート | 条件付き: バージョン変更やCHANGELOG相当の差分を検知した場合のみ | 独立 | doc/design.md §リリースノート |

## トリガー判定の手続き

各カテゴリの該当可否は、CP-Fタスク実行時に `doc-updater` が `git diff` を根拠に判定する
（`templates/doc-sync-task-template.md` Step 1）。トリガーに該当する根拠 `file:line` を
示せないカテゴリは生成しない（無条件生成の禁止）。
