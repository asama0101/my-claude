---
description: マージ済みPRをローカルmainへ同期しブランチを片付ける
---

現在のブランチに紐づくPRがマージ済みか確認し、マージ済みならローカルの main を同期してブランチを片付ける。

## 手順

1. `git branch --show-current` で現在のブランチを確認する。`main`/`master` の場合は「片付け対象のブランチにいません」と報告して停止する。

2. `gh pr view --json state,mergedAt,number,title` で現在のブランチに紐づくPRの状態を確認する。PRが見つからない場合はその旨を報告して停止する。

3. PRの `state` が `MERGED` でない場合（`OPEN`/`CLOSED`）、現在の状態をそのまま報告して停止する。マージ済みと推測して先に進めない。

4. `state` が `MERGED` の場合、コマンドが呼ばれたこと自体をユーザーの承認とみなし、追加確認なしで次を実行する。
   a. `git fetch origin`
   b. `git checkout main`（リポジトリの既定ブランチ名に合わせる。`master`運用のリポジトリなら`master`）
   c. `git pull --ff-only origin main`
   d. 元のブランチを `git branch -d <branch>` で削除する。`-d` が「完全にマージされていない」旨で失敗した場合は `-D` へ自動で切り替えず、失敗内容をそのまま報告して停止する（破壊的操作の自動昇格はしない）

5. 新しい `main` の HEAD コミットハッシュとメッセージ、削除したブランチ名を報告する。

## 禁止事項

- PRが `MERGED` であることを `gh pr view` で確認する前に、マージ済みと仮定して同期を進めない
- `git branch -d` が失敗した場合に `-D` へ自動で切り替えない（ユーザーに判断を委ねる）
- リモートブランチの削除は行わない（`gh pr merge` の既定設定で自動削除されるのが通常のため）
